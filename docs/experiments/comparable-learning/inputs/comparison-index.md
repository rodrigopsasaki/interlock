## Assessment and limitations

Review-pair-assessment and test-pair-assessment are root and independent source
judgments supplied for challenge, not ground truth. Root knew conditions. Review
assessment initially omitted condition labels where practical but report content
partially disclosed them; test assessment was unblinded. No causal claim follows.
See the final read audit for actual exclusions and disclosure limitations.

The comparison assembly first failed existing tests because legacy fixture inputs
were missing. Exactly nine graph/brief fixtures were restored equally; no completed
prior debrief, notes or outcome was restored. A root index setup error briefly
omitted source entries from an intermediate commit while files stayed intact on
disk; it was corrected and source equality/full-suite preflight verified before
any comparison worker launched. The manifests here retain both qualifications.

This was procedural read isolation, not a security sandbox. In particular,
test-design-b's broad search returned old and sibling brief content and its
filenames-only disclosure is inaccurate. Do not treat that pair as clean
attribution. No completed prior report or debrief was found in the exposed output.

Citation-acceptance-review and hypothesis-acceptance-review retain source repair
proof, startup failure/recovery and earlier holds. The citation release uncovered
a timer defect: sessionWait captures time before a blocking wait, then arms grace
with that stale value. An advertised 300 seconds lasted about 83 seconds after
narration; same-session manual judgment later produced fresh proof. No timer fix
was added to the frozen code. Subsequent report workers used clean final handback
without an intermediate checkpoint. Treat this as an operational defect requiring
its own future regression, not a reason to invent a new framework.

Eight workers have launched so far, including failed startup and the authorized
extra source repair; the outcome read and strategy proposal are the last two
initial nodes. Setup, repair and orchestration costs are not included in the
prompt-to-settled-screen intervals. Visible byte counts are not billed tokens or
evidence of causal savings. Equality, weaknesses and missing transfer remain data.
